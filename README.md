🧠 OVERVIEW

This repository contains an end-to-end Natural Language Processing (NLP) pipeline including:
Data preprocessing
Text cleaning
Feature engineering (TF-IDF, embeddings, n-grams)
Classical ML models
Deep learning models (optional)
Evaluation metrics
Deployment-ready script/notebooks


🔧 FEATURES
✔ Automated text preprocessing (lowercasing, stopwords, stemming/lemmatizing)
✔ Supports ML algorithms: Logistic Regression, SVM, Random Forest
✔ Supports NLP feature extractors:
   • TF-IDF
   • Bag of Words
   • Bigrams / Trigrams
✔ Highly modular code structure
✔ Evaluation with:
   • Accuracy
   • Precision, Recall, F1
   • Confusion Matrix
✔ Exportable model + vectorizer
